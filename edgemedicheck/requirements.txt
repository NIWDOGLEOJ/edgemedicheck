# EdgeMediCheck runtime dependencies
#
# Core pipeline -- required on both laptop and Raspberry Pi.
# Upper bound is deliberate. OpenCV 5.0 reordered the return tuple of
# BarcodeDetector.detectAndDecodeMulti (4.x: retval, info, type, points;
# 5.0: retval, info, points, straight_code), so an unbounded ">=4.8.0" quietly
# installed 5.0 and fed corner coordinates into the barcode symbology field.
# barcode.py now detects the layout at runtime, but pin the major version so a
# future release cannot change the API underneath a Raspberry Pi deployment.
opencv-python-headless>=4.8.0,<6   # use opencv-python if you need cv2.imshow
numpy>=1.24.0
Pillow>=10.0.0
pytesseract>=0.3.10
Flask>=3.0.0
# Needed by `run.py serve --https`, which issues the self-signed certificate
# that lets the live screen use the camera of the device viewing it. Browsers
# refuse camera access to a page served over plain HTTP on a LAN address, so
# without this the live screen falls back to the server's own camera.
cryptography>=41.0.0

# The Tesseract OCR *binary* is a separate, non-pip install:
#   Debian / Ubuntu / Raspberry Pi OS : sudo apt install tesseract-ocr
#   Arch / Manjaro / EndeavourOS      : sudo pacman -S tesseract tesseract-data-eng
#   macOS                             : brew install tesseract
#   Windows                           : https://github.com/UB-Mannheim/tesseract/wiki
#                                       then set EMC_TESSERACT_CMD to tesseract.exe
#
# On Arch the language data is packaged separately from the engine, so
# installing `tesseract` alone gives a binary that fails at run time with
# "Failed loading language 'eng'". `tesseract-data-eng` is not optional there.
